민감 구역은 위험도 0.5 이상인 바다입니다. 누적 위험 노출은 지나간 거리마다 위험도를 곱해 더한 값입니다.

1단계 · 데이터

출현 기록을 격자에 모읍니다

바다를 0.02° (약 2 km) 격자로 나누고, 생물 출현 기록 하나하나를 주변 격자에 퍼뜨려 서식 밀도를 추정합니다 (가우시안 커널 밀도 추정, 반경 약 7 km).

2단계 · 위험도

수온으로 민감도를 보정합니다

위험도 = 서식 밀도 × (0.4 + 0.6 × e^−((수온 − 적정)/5)²)
수온이 산란 적정 수온과 같으면 서식 밀도가 그대로 위험도가 되고, 멀어지면 최대 60% 낮아집니다.

3단계 · 항로

A*로 비용이 가장 작은 길을 찾습니다

비용 = 거리 × (1 + 가중치 × 위험도)
가중치 = 회피 가중치 × (0.5 + 1.5 × 소음)
가중치가 0이면 최단 항로와 같고, 커질수록 민감 구역을 크게 돕니다.

라이브러리 관리자에서 OneWire와 DallasTemperature를 설치합니다. 스케치는 9600 bps로 T:18.5,N:42 형식의 줄을 보냅니다.

연결 버튼은 PC의 Chrome 또는 Edge에서, 이 페이지를 파일로 저장해 연 경우에만 동작합니다. 아두이노 IDE의 시리얼 모니터는 닫아 두세요.

// SAFE Route 센서 송신 (Arduino Uno)
#include <OneWire.h>
#include <DallasTemperature.h>

const int PIN_TEMP  = 2;    // DS18B20 DATA
const int PIN_SOUND = A0;   // 소리 센서 AO
const int NOISE_MAX = 300;  // 이 진폭을 소음 100%로 봄 (센서에 맞게 조정)

OneWire oneWire(PIN_TEMP);
DallasTemperature sensors(&oneWire);

void setup() {
  Serial.begin(9600);
  sensors.begin();
}

void loop() {
  // 0.2초 동안 소리 파형의 최대-최소 차이(진폭)를 잰다
  unsigned long t0 = millis();
  int lo = 1023, hi = 0;
  while (millis() - t0 < 200) {
    int v = analogRead(PIN_SOUND);
    if (v < lo) lo = v;
    if (v > hi) hi = v;
  }
  int noise = constrain(map(hi - lo, 0, NOISE_MAX, 0, 100), 0, 100);

  sensors.requestTemperatures();
  float tempC = sensors.getTempCByIndex(0);

  Serial.print("T:");
  Serial.print(tempC, 1);
  Serial.print(",N:");
  Serial.println(noise);
  delay(300);
}
데이터 출처: OBIS (obis.org) 해양 생물 분포 데이터. 처음 화면의 출현 기록은 동작을 보여 주려고 만든 가상 예시이며 실제 관측값이 아닙니다.
